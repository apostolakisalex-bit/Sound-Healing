# Sound Healing Greece Work Project

Ένα ενιαίο σημείο συνέχειας για τον σχεδιασμό και την ελεγχόμενη εξέλιξη του υπάρχοντος app.

1. [Master Product Specification](MASTER_PRODUCT_SPECIFICATION.md) — το κεντρικό προϊόν, κανόνες, data model, acceptance criteria και open decisions.
2. [Implementation Phases and Emergent Prompts](IMPLEMENTATION_PHASES.md) — δέκα ελεγχόμενες φάσεις πάνω στο υπάρχον repo.
3. [Technical Baseline](TECHNICAL_BASELINE.md) — τι επιβεβαιώθηκε στον κώδικα και τι χρειάζεται διόρθωση.
4. [Form Catalog](FORM_CATALOG.md) — φόρμες, πεδία, κλίμακες και ελλείψεις.
5. [Source Register](SOURCE_REGISTER.md) — προέλευση και κάλυψη πηγών.
6. [Change Log](CHANGELOG.md) — ιστορικό και τρόπος ενημέρωσης.
7. [Επόμενο βήμα στο Emergent](EMERGENT_NEXT_STEP.md) — πρόσφατη επιβεβαίωση repo και πρακτική διαδρομή ανάπτυξης/ενημέρωσης.

Η έκδοση 1.0 δημιουργήθηκε στις 29/09/2026. Η υλοποίηση δεν έχει εκτελεστεί. Συνεχίζουμε από το P0 και ενημερώνουμε τα ίδια αρχεία. Οι πηγές στο `sources/` δεν τροποποιούνται. Το `work/evidence/` περιέχει τοπικά τεκμήρια και δεν προορίζεται για δημόσια δημοσίευση.
